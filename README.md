✦ DYNASTIYA — Restaurant Website

An elegant digital experience for Dynastiya restaurant in Zolochiv, Ukraine.

A modern, responsive website concept designed to present the restaurant, showcase its menu, collect demo feedback, and help guests find the location.

✨ Features

- Elegant Design — refined typography, warm colors and premium visual style.
- About Us — a dedicated section introducing the restaurant.
- Interactive Menu — category filters and dish cards.
- Guest Reviews — demo ratings for the restaurant, dishes, service and atmosphere.
- Photo Gallery — visual showcase section.
- Contact Information — phone number, address and Google Maps link.
- Responsive Layout — optimized for desktop, tablet and mobile.
- Interactive Elements — favorites, star ratings and mobile navigation.

🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

🚀 Run Locally

1. Download or clone this repository.
2. Open "index.html" in your browser.
3. Internet access is required for externally hosted fonts and images.

⚠️ Demo Notice

This repository contains a website concept for presentation and approval.

Menu items, prices, photographs, opening hours and social media links must be verified with the restaurant owner before publication.

The review form currently stores demo reviews locally in the visitor's browser. It does not publish reviews publicly or send them to the restaurant.
