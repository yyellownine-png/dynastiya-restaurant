# Династія — демонстраційний сайт

Преміальна концепція сайту для закладу «Династія» у Золочеві. Темна ресторанна палітра, золоті акценти, горизонтальна навігація, адаптивний вигляд для телефону та комп’ютера.

## Файли
- `index.html` — структура сайту
- `assets/style.css` — дизайн та адаптивність
- `assets/app.js` — фільтри меню, мобільна навігація, обране та демоформа відгуків

## Запуск
Відкрийте `index.html` у браузері або завантажте файли в корінь репозиторію GitHub Pages.

## Важливо
Це концепт, а не офіційний сайт. Фото, страви, ціни, адреса, телефон, графік роботи й соціальні мережі потрібно перевірити та погодити із власницею перед публікацією. Форма відгуків демонстраційна: відгуки зберігаються тільки у локальному браузері й нікуди не надсилаються. Частина фото та шрифти завантажуються з інтернету.
